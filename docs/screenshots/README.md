# Screenshots

Drop your screenshots here with these **exact filenames** so they appear in the main README automatically:

| Filename | What to capture |
|---|---|
| `landing.png` | The homepage hero (`/`) |
| `dashboard.png` | The candidate dashboard with stats, streak calendar & charts |
| `interview.png` | An AI interview room mid-session |
| `report.png` | A completed interview feedback report |
| `coach.png` | The Coach chat widget open |
| `profile.png` | The candidate profile (view mode with tech-stack badges) |

## How to add them (easiest way)

1. Open your live site → take a screenshot of each page (Cmd/Ctrl + Shift + 4 on Mac, Snipping Tool on Windows)
2. Rename each to match the table above
3. On GitHub: open this `docs/screenshots/` folder → **Add file → Upload files** → drag them all in → **Commit**

That's it — the images will render in the main README instantly. Recommended width: ~1200px, PNG or JPG.
